# 76 — x402 pay-per-call API

## Main post

The ArcTools API now takes payment from bots. Per call, in USDC, on Arc.

No API key. No account. No invoice. Your agent asks for data, gets HTTP 402 with a price, signs a USDC authorization, asks again, gets the data. The USDC settles on-chain seconds later. That is x402 — the payment standard Coinbase published — running natively on Arc.

What is for sale
- token-stats · 0.005 USDC — price, changes, volume, traders, market cap
- dev-audit · 0.02 USDC — deployer history, funder clusters, bundles, clone farms
- sell-sim · 0.03 USDC — a real buy-then-sell round trip simulated on-chain, honeypot verdict
- token-report · 0.04 USDC — all three in one call

Why Arc makes this easy: its USDC is Circle's FiatTokenV2, so a signed EIP-3009 authorization is all a payment takes. No custody, no allowances, no gas on the caller's side. The same signed payment sent twice returns the same answer and is never charged twice. Nothing is charged for a 402 or an error.

Every payment lands in the ArcTools treasury and is burned into ARCT, like every other fee.

Free endpoints stay free for humans. The paid ones have no rate limit.

arctools.fun/api-docs — reference client is 40 lines.
